# Documentation RAG pipeline

Turns a folder of raw Markdown documentation into:
- a cleaned sections dataset
- an ontology
- two LoRA adapters (Qwen2.5)
- three RAG systems evaluated on synthetic questions

Everything runs from [`main.ipynb`](main.ipynb).

## Requirements

- Python 3.10 or newer
- An NVIDIA GPU is recommended. The pipeline was run on an RTX 3080 Ti (12 GB), where a full run takes about 20 minutes. It also works on CPU, much more slowly.
- About 6 GB of disk for the models, downloaded on first use: `Qwen/Qwen2.5-0.5B-Instruct`, `Qwen/Qwen2.5-Coder-0.5B-Instruct` and `BAAI/bge-m3`. None of them needs a Hugging Face login.
- The raw documentation folder (`docs_raw/`). It is not included in this repository.

## Setup

```bash
git clone <this-repo-url>
cd meli_challenge_llm

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt    # also installs this project's src/ code as the rag_etl package
```

Notes:
- On Debian/Ubuntu, if `python3 -m venv` fails, install the venv package first: `sudo apt install python3-venv`.
- `pip install -r requirements.txt` installs the default PyTorch build. For a specific CUDA version, install `torch` first by following the instructions at https://pytorch.org, then run the line above.
- If you use [uv](https://docs.astral.sh/uv/), `uv sync` creates the same environment from `pyproject.toml` and `uv.lock`.

## Running

1. Put the raw documentation somewhere on disk, laid out as `<docs_raw>/<project_name>/<version>/**/*.md`.
2. Tell the notebook where it is: edit `DOCS_RAW_DIR` in section 1 of `main.ipynb`, or set the environment variable:
   ```bash
   export DOCS_RAW_DIR=/path/to/docs_raw
   ```
3. Run the notebook:
   ```bash
   jupyter lab main.ipynb
   # or headless:
   jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 main.ipynb
   ```

All outputs are written to `data/`. In notebooks or scripts, import `rag_etl` before `torch`: it sets environment variables that torch needs on machines without the Python development headers.

## Repository layout

| Path | Contents |
|---|---|
| `main.ipynb` | The full pipeline: parameters → imports → ETL → LoRA trainer → RAG experiments |
| `etl_experiments.ipynb`, `lora_trainer.ipynb`, `rag_experiments.ipynb` | The individual experiments, with their findings |
| `src/rag_etl/` | Pipeline code: parsing, flags, ontology, LoRA training, RAG |
| `data/ontology_source/` | Per-section entity and relationship annotations, plus synonyms (the ontology's source) |
| `data/ontology.json` | The ontology built from `data/ontology_source/` |
| `data/synthetic_question.json` | 80 answerable and 20 unanswerable evaluation questions |

Everything else in `data/` is generated by `main.ipynb` and is not tracked.
